# 喷嚏图卦 · 每日图卦

喷嚏网 xilei 每日新闻栏目的日报阅读版。

- 每日 18:00（北京时间）自动抓取最新一期，五主题分类（经济与民生 / 社会与健康 / 国际 / 科技与财经 / 文化娱乐），分色排版
- 页面保留最近 7 天数据，顶部按钮可切换任意一天
- 每条新闻带"来源"链接，点击打开原文并定位到该条
- 敏感条目自动过滤，不收录

## 文件

- `index.html` — 日报页面（单文件自包含）
- `data.json` — 最近 7 天数据
- `fetch.py` — 每日自动更新入口
- `_build.py` / `_render.py` — 数据构建与页面渲染
- `.github/workflows/daily.yml` — 每日 18:00 定时任务

## 手动触发

在仓库 Actions 页对 `pentu-daily` workflow 点 Run workflow 即可立即更新。
